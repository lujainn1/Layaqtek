# Layaqtek
AI-assisted calorie &amp; macro tracking for Arabic-speaking users + progress analysis 
# لياقتك — تطبيق تتبع السعرات الحرارية

**لياقتك** هو تطبيق ويب عربي متكامل لتتبع السعرات الحرارية والمغذيات الكبرى بشكل يومي.
يعتمد على قاعدة بيانات غذائية موثوقة من USDA FoodData Central، ويدعم تحليل الصور بالذكاء الاصطناعي،
ومتابعة التقدم الأسبوعي، وتخصيص الأهداف الغذائية.

**Layaqtek** is an Arabic-first (RTL) full-stack web app for daily calorie and macro tracking.
Features a 70+ food database sourced from USDA FoodData Central, AI-powered food image analysis,
progress analytics, customizable macro goals, and water intake tracking.
Built with  React + Vite, Node.js / Express,  Firebase Firestore, fully RTL.
