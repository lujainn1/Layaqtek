6 طبقات الأمان

🔐 Authentication & Authorization
JWT tokens بصلاحية 7 أيام — يتجدد عند كل تسجيل دخول
كل endpoint محمي يتطلب Authorization: Bearer <token>
Firebase Admin SDK يتحقق من صحة token قبل كل طلب
401 تلقائي يعيد التوجيه لصفحة تسجيل الدخول
كلمات المرور تُدار بالكامل عبر Firebase Auth (لا تُخزن في Firestore)
🛡️ API Security
Helmet.js يضيف 14 HTTP security header تلقائياً
CORS مقيّد: localhost:5500, 5501, 3000 فقط في dev
Rate limiter عام: 100 طلب / 15 دقيقة لكل IP
AI endpoint rate limit منفصل (عدد محدود / ساعة)
express-validator يتحقق من كل input قبل المعالجة
🔑 Secrets Management
مفتاح OpenRouter لا يُكشف للـ frontend — كل طلبات AI تمر عبر الـ backend
Firebase credentials في .env فقط — غير موجودة في الكود
JWT secret في .env
ملف .env مدرج في .gitignore
📊 Data Isolation
كل مستخدم يصل فقط لبياناته — UID من JWT token
Firestore rules: كل وثيقة مؤمّنة بـ uid المستخدم
حجم الصور محدود بـ 10MB في الـ backend وفي Express body parser
SQL injection غير ممكن — Firestore SDK, لا raw queries

7 خوارزمية حساب السعرات

Mifflin-St Jeor BMR Formula:
// ذكر
BMR = 10 × weight(kg) + 6.25 × height(cm) − 5 × age + 5

// أنثى
BMR = 10 × weight(kg) + 6.25 × height(cm) − 5 × age − 161

// TDEE — Total Daily Energy Expenditure
TDEE = BMR × activityMultiplier
sedentary: ×1.2 | light: ×1.375 | moderate: ×1.55 | active: ×1.725 | veryActive: ×1.9

// هدف السعرات
targetCalories = max(1200, TDEE + goalAdjustment)
lose: −500 | maintain: 0 | gain: +300

// توزيع الماكروز
protein = round(targetCalories × 0.30 / 4) // 30%
carbs = round(targetCalories × 0.40 / 4) // 40%
fat = round(targetCalories × 0.30 / 9) // 30%
